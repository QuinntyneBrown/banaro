Responsive behaviour

Below 480px the menu label hides and the 44px icon target remains. Below 1024px links live in the popover. At 1024px inline links and sign-in return.

WidthReview
360pxSingle column, wrapping text, comfortable controls; internal tables may scroll.
768pxRelated controls may align; retain reading order.
1280pxWide shell with a 74rem content cap; do not stretch prose past its measure.

Theming

Use semantic roles from the single token stylesheet. Light wrappers reset inherited dark roles; the dark theme uses warmer charcoal surfaces and light sage accents. Component overrides keep the --bn- prefix.

Accessibility

Role and pattern

WAI-ARIA disclosure pattern. Tab visits links and controls. Native popover trigger opens the compact navigation; Escape dismisses it.

Keyboard

KeyEffect
Tab / Shift+TabTab visits links and controls. Native popover trigger opens the compact navigation; Escape dismisses it.
Enter / SpaceNative activation on buttons and appropriate inputs; links activate with Enter.
EscapeDismiss open overlays; leave field contents intact. Passive components have no Escape action.

Focus

Keep visible focus on the real control, using the shared 2px ring with 3px offset. Never move focus on background refresh.

Labelling

Use Directory, Projects, Events and Matching in the same order.

Contrast

Motion

Colour changes use 240–420ms; lifts use 420ms and entrance uses 640ms. Reduced motion removes animations and transforms while preserving status text.

Touch

Use at least 24px targets; primary mobile actions and label rows are at least 44px. Do not rely on hover for access to controls.

Content

Use Directory, Projects, Events and Matching in the same order.
