Principles

Use the shared spacing steps inside components and between sections. Half-step 2px is reserved for fine control geometry; primary layout gaps use whole 4px multiples.

Inside versus between

Use 8px between an input and its help, 12px between closely related controls, 24px inside a card and 24px between fields. Home sections use 96px at base and 128px from 1024px. Space communicates relationship: reduce it within a question before adding more columns.

Normalisation

Micro-spacing at 1.6–6px was snapped to 4/8px except the 1px stroke and 3px focus offset, which serve specific optical and accessibility purposes. The drift log preserves each changed declaration.
