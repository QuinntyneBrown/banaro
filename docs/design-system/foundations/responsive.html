Principles

The same information and reading order work at 360px, 768px and 1280px. The shared grid changes at 768px and 1024px; the sheet threshold is 640px.

Zoom and reflow

Use rem dimensions and content-driven heights. Long names, translated labels and validation help wrap. At 320px and 400% zoom, avoid two-dimensional page scrolling; actual data tables may scroll within their own wrapper.

Pointer and touch

Show essential controls without hovering. Comfortable targets are at least 44px. Fixed bottom elements include the safe-area inset. Use dynamic viewport height for tall overlays so mobile browser chrome cannot clip controls.
