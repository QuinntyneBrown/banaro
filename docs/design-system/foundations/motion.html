Principles

Motion explains continuity: 240ms colour feedback, 420ms hover movement, 640ms overlay entrance and 900ms photographic emphasis. Avoid motion that delays access.

Choreography

Only the thing being used moves. Card lift is small; section drift never hides content. Toast and dialog entrance use the same entering curve. Presence breathing is decorative, never the only online signal.

Reduced motion

Disable animation and transforms completely when reduced motion is requested. Keep busy text and progress values readable. The source’s near-zero duration override is retained, with an explicit no-animation rule to prevent tight looping.

Live specimens

Replay is disabled visually under reduced motion; content remains available.
