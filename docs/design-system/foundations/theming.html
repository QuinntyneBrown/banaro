Principles

Set data-theme on a root or specimen wrapper. Light uses oat and birch; dark uses warm charcoal. Native controls inherit color-scheme so they follow the same choice.

Preference order

An explicit theme wins; otherwise use the operating-system preference. Documentation honours ?theme=light or ?theme=dark, saves a chosen theme, and offers the t shortcut outside form controls. Explicit light specimen wrappers reset inherited dark roles.

Token tiers

Palette and font definitions establish raw values. Color, text, space, radius, shadow, layout and interaction names give them purpose. Component knobs alias roles and keep --bn-. Add a brand theme by overriding roles; rerun every contrast pair before accepting it.

Portable export

tokens.json stores DTCG $type/$value entries, aliases and theme extensions. Breakpoint overrides and preference media queries remain documented in CSS; the JSON export is not a replacement for responsive CSS.
