Principles

Use the existing five rounded steps plus a pill sentinel. Medium corners are normalised from 14px to 16px; portrait identity remains square with rounded corners.

Assignment

XS: checkbox. SM: code and quiet wells. MD: inputs and portraits. LG: cards and menus. XL: form cards and sheets. Full: buttons and badges. Match radius to the container’s size instead of making every element a pill.

Strokes

Hairlines are 1px, strong outlines 2px. Focus width and offset have separate interaction roles. Keep native control outlines in forced-colour mode.
