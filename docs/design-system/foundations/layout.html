Principles

The content cap is 74rem, with 4, 8 and 12 columns. Margins and gutters grow at 768px and 1024px. These values preserve the selected design rather than substituting a generic grid.

Page templates

Public pages use a centred wrap. Forms use a narrow single-column reading area. Directory screens place filters beside a two-column result grid at laptop width. Detail pages combine a reading column with an RSVP or matching aside.

Geometry roles

Named size roles preserve repeated avatar, dialog, content-measure and media geometry found in the mocks. These roles are not a free spacing scale: use space-* for gaps and reserve geometry roles for the component dimension described by their name.
