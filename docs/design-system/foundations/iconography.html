Principles

The mock icons use a 24-unit viewBox, rounded joins and currentColor. Default display is 20px and the compact form is 16px; the line stroke is 1.5 units.

Meaning and naming

A decorative icon beside visible text uses aria-hidden. A standalone control needs an action name such as Edit profile. Never put a title on a decorative SVG and repeat the same spoken label.

Usage

Use the small building-and-sun mark only for identity. Search, plus, arrow, message, calendar and close icons keep one meaning across the product. Status combines an icon or dot with words.
