Typography

Principles

Manrope carries every product role; JetBrains Mono is reserved for code. Body text remains 16px with a relaxed 1.65 line height, while display headings use light weight and tight tracking.

Hierarchy

Use one h1 per product page and ordered h2/h3 sections. Display text is for Home’s promise; form titles use heading roles. Metadata is at least 12px. The prior 11px notification count is normalised to 12px.

Measure and fluid headings

Cap prose at 58ch. The h1 and display roles use clamp to grow within defined limits; body text never shrinks with the viewport. Avoid fixed heights around labels, help and translated copy.
