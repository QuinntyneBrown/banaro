Loading builders
Loading builders

When

Use inline text for local field work, a toast for a completed brief action, a banner for continuing account/network conditions and a dialog only for a decision.

Structure

Keep loaded geometry visible while refreshing. Skeletons reserve future content; a spinner sits beside the action that was pressed; progress shows only known completion.

States

Pending, success and recoverable failure retain surrounding context. Optimistic changes provide Undo and rollback visibly when saving fails.

Responsive

Reserve space for loading content at each breakpoint. Toasts use the bottom available width on phones and a capped stack on tablets.

Accessibility

Label busy regions, keep decorative skeletons aria-hidden, and announce outcomes without stealing focus. Pause transient timing on hover/focus; errors persist.

Content

Use Project saved or Message not sent. Your note is still here. Try again.
