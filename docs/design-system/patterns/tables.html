When

Use cards for builder discovery, chronological rows for events, lists for conversation browsing and native tables when users compare columns.

Structure

Put search, filters and sort before results. Keep a visible count, active-filter summary and predictable pagination. Selection needs an explicit bulk-action context.

States

Loading reserves row/card geometry; no results offers filter recovery; failure retains controls. Sort, selection and current page are represented in semantics as well as appearance.

Responsive

Directory cards go from one to two columns; filters join as a sidebar at 1024px. Tables scroll internally rather than shrinking labels.

Accessibility

Table headings use scope and a caption; sorting uses aria-sort on the heading. Native lists keep item semantics. Each row action names its object.
