Overview

When

Distinguish a first-run collection, filtered no results, permission denial and load failure. Each needs a different next action.

Structure

Keep the shell, show a plain title and one sentence, then one primary action. Secondary help may explain more without competing.

States

First-run invites creation. No results offers clearing filters. Failure offers Retry with context preserved. Forbidden returns to an accessible destination.

Responsive

Use the same content order in compact panels and full-screen states. Do not rely on a large illustration at mobile width.

Accessibility

Do not automatically move focus on background emptiness. On route navigation focus the heading. Keep errors identified by words, not only the red icon.
