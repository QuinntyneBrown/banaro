When

Use a dialog for a short introduction or destructive confirmation, a sheet for mobile filters, a popover for a short nonmodal action group, and a page for long editing.

Structure

Name the panel with its title. Keep a close control and safe action. Body scrolls; actions remain reachable. Avoid stacked decisions when one clear panel can do the task.

States

Open → busy → success/close or invalid/failed. Preserve entered data after failure. Never close a failed form and lose its answers.

Responsive

Below 640px dialogs become full-width bottom sheets. At larger sizes centre a capped panel. Safe-area padding protects mobile bottom actions.

Accessibility

Move focus inside a modal, keep Tab within it, allow Escape and restore the opener. Set aria-modal only while the page is actually inert; static specimens are labelled regions.

Content

Name the loss: Delete account or Delete Psalter. Explain which records disappear before confirmation.
