# Offline fonts for the concept mocks

Latin-subset `woff2` copies of open-licence families from Google Fonts (SIL Open Font Licence 1.1,
or Apache 2.0 for Roboto), so every mock opens from disk without a network. `fonts.css` declares
every face; a browser downloads a file only when a page uses that family.

Families: Anton, Archivo, Atkinson Hyperlegible, Baloo 2, Bebas Neue, Big Shoulders Display, Bodoni
Moda, Bricolage Grotesque, Caveat, Cinzel, Cormorant Garamond, DM Serif Display, Darker Grotesque,
EB Garamond, Fraunces, Fredoka, Gochi Hand, Google Sans Flex, IBM Plex Mono, IBM Plex Sans,
Instrument Serif, Inter, JetBrains Mono, Josefin Sans, League Spartan, Libre Franklin, Manrope,
Michroma, Monoton, Newsreader, Nunito, Old Standard TT, Orbitron, Outfit, Permanent Marker, Playfair
Display, Press Start 2P, Righteous, Roboto, Rubik, Shrikhand, Silkscreen, Sora, Source Serif 4,
Space Grotesk, Space Mono, Syne, Unbounded, UnifrakturMaguntia, VT323.

When a concept is chosen, keep only the families it uses and move them into the design system.
