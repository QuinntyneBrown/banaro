Close control states

The panel itself has no pointer states; hover, focus and active belong to the close control (forced with data-state). Disabled is the busy, not-closable case.

Responsive

Each frame is a real viewport with a backdrop and a live role="dialog". Below 576 px the panel is a bottom sheet (top corners rounded, bottom square); from 576 px it is centred at up to 32 rem. The frames apply the height cap from D-9 inline, because components.css does not yet cap the panel in the .backdrop form.

Stacking (AC-4): session-expired opens as a second backdrop and panel above an open dialog; only the top panel is reachable. Motion (AC-26): the entrance rise over --duration-slow is removed under reduced motion, so it is not drawn here. Performance (AC-28) is measured by the Dialog perf-test scenario. Focus behaviour (AC-15, AC-16, AC-18) is interactive and is specified in the Markdown.
