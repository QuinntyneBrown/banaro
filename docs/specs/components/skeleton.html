Skeleton

Placeholders shaped like the content that is loading, so the page does not shift when it arrives. Requirements: skeleton.md. Design system: skeleton.

Variants

Shapes: title, text, short text, photo, circle, pill, block. AC-4, AC-10
Card, media layout (builder, project, event placeholders). AC-1
Card, custom layout with projected shapes (builder-profile, project-detail, dashboard aside). AC-2, AC-6
One-off geometry: 96 px profile photo, 40 % line, action pill at control height. AC-3, AC-5
Form placeholders: photo, inputs at --control-height-lg, a text area block (profile-edit, settings). AC-7
Rows: notifications (2.75 rem photo, 55 % line, 4 rem time). AC-8, AC-9, AC-11

Sizes

No size API: each shape has its design-system size, and width, height and radius match it to the final element.

States

Skeletons have one visual state, loading. With motion allowed they pulse (opacity to 0.55 every --duration-breath); under reduced motion they are still. A still picture shows both the same. AC-12, AC-15

Loading (the pulse is captured mid-cycle in screenshots). AC-15

Responsive

The directory loading grid: one column at 320 and 360 px, two columns from 768 px, the same grid the loaded cards use.

Contrast

Skeletons are decorative and hidden from assistive technology, so no contrast minimum applies; the pairs are shown for reference.
